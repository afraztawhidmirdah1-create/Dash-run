# DASH RUN — Made by Afraz Studio

A mobile-friendly endless-runner prototype inspired by lane-based runner games.

## Included
- Home screen with DASH RUN + “Made by Afraz Studio”
- PLAY and SHOP buttons
- 3-lane runner gameplay
- Coin collection and persistent coin balance
- Four skins, including unlockable skins
- Obstacles, jumping, increasing speed, score
- Touch swipe controls + keyboard controls
- Procedural natural landscape, road perspective, lighting and character rendering

## Run
Open `index.html` in a modern browser. For Android packaging, import this web app into Android Studio using a WebView/Capacitor wrapper and build a signed APK.

The current environment does not contain the Android SDK/build tools, so a compiled APK cannot be produced here without installing that toolchain.
